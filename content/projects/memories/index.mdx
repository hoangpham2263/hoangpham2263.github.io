## Overview

A personal travel map of Vietnam's 34 provinces and cities: provinces I've been to are coloured on the map, with the places and photos from each trip.

- **Role:** Personal project
- **Year:** 2026
- **Live:** [hoangpham.is-a.dev/memories](https://hoangpham.is-a.dev/memories/)
- **Source:** [github.com/hoangpham2263/memories](https://github.com/hoangpham2263/memories)

## Features

- Interactive map of the 34 provinces, filtered by year
- Places grouped by area, with drag and drop and auto-fill from a Google Maps link
- Photos stored in Google Drive and grouped into trips
- A list of places I plan to visit, with dates
- Stats for photos, trips, provinces and places

## Tech

- Leaflet for the map
- Google Drive API for photos
- Cloudflare Workers and KV for data
- Hosted on GitHub Pages
