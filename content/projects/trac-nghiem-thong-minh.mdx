Online quiz and exam platform for students, with practice tests, study materials and personality tests (IQ, EQ, MBTI, DISC).

- **Client:** Trắc Nghiệm Thông Minh
- **Type:** Education
- **Year:** 2026
- **Company:** [Puramu](https://www.puramu.com/)
- **Role:** Web Developer — built the WordPress theme and features from the design, optimized speed and SEO
- **Live:** [tracnghiemthongminh.com](https://tracnghiemthongminh.com/)

## Data Pipeline

The quiz library was filled by a crawler I wrote in Python:

- Read target URLs from sitemaps and URL lists, then crawl the HTML with Requests and BeautifulSoup.
- Extract questions, answers and exam details (subject, school, year, difficulty, question count) into clean JSON.
- Import quizzes into WordPress through a custom REST endpoint, creating categories and quiz meta fields automatically.
- Track progress and failed URLs so long runs can resume and retry; separate runs for exam papers and IQ, EQ, MBTI and DISC tests.
